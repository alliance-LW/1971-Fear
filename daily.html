DAILY COMMANDER ROUTINE

DAILY

A practical FEAR checklist for getting stronger every day without wasting high-value items.

CHECKLIST

Daily Core

  • Claim daily and event rewards.
  • Use alliance help and make Alliance Tech donations.
  • Run gathering marches when you will be offline.
  • Check stores before reset and collect free/earned items.
  • Join alliance rallies and scheduled activities.
LAST WAR TIP

Save Before You Spend

Before using speed-ups, hero shards, skill medals, drone materials or big upgrades, check the current and upcoming VS/Arms Race scoring windows. One upgrade can often earn progress in more than one event.

RECOMMENDED

FEAR Recommendation

Build a repeatable 10–15 minute login routine. Prioritize alliance participation, stamina use and free rewards first; make expensive upgrades only when they also advance an event.

AVOID

Common Waste

Do not open every resource chest or burn every speed-up simply because it is available. Keep a reserve for VS days, emergency healing and major HQ/research requirements.
